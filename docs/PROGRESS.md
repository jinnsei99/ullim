- 결정: 단계 0에서 저장소 분리(0-B)를 자동 점검(0-C)보다 먼저 한다. 이유: 점검은 GitHub Actions에서 도니, 새 저장소에 한 번만 만든다.
- 확인하지 못한 것: 앱을 열어 보지 않았다(문서만 만듦). 진짜 저장소를 보지 못해 다른 앱 폴더·아이콘 파일·커밋 메시지 습관은 확인하지 못했다(→ 위 기록에서 확인함).
